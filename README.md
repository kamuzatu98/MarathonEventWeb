# MarathonEventWeb

`MarathonEventWeb` is an ASP.NET Core MVC web application designed to manage marathon event scheduling, categories, and account profiles. Built using Entity Framework Core and styled with Bootstrap, the application provides a responsive administrative interface for full CRUD operations.

---

## 🚀 Features

* **Event Management:** Full Create, Read, Update, and Delete (CRUD) operations for marathon events.
* **Account Administration:** Manage user accounts with defined roles (`FirstName`, `LastName`, `Email`, `Role`, `CreatedAt`).
* **Entity Framework Core Integration:** Automated data modeling with primary keys and database field mappings.
* **Responsive Layout:** Clean, accessible Bootstrap UI design across all controllers and views.

---

## 🛠️ Built With

* **Framework:** ASP.NET Core MVC (.NET 8 / 9)
* **Language:** C#
* **Database ORM:** Entity Framework Core
* **Database Engine:** Microsoft SQL Server
* **Frontend:** Razor Views (`.cshtml`), Bootstrap 5, HTML5, CSS3
